Migração de votos entre turnos ?O voto é secreto, então não sabemos quem mudou de candidato. Mas comparando os totais do 1º e do 2º turno em cada município, conseguimos calcular quanto cada candidato cresceu e estimar de onde vieram esses votos.

Entre o 1º e o 2º turno, milhões de votos foram redistribuídos. Eles vieram de quatro fontes: eleitores que votaram em outros candidatos no 1º turno e precisaram escolher entre Lula e Flávio; pessoas que tinham votado em branco ou nulo e desta vez escolheram um candidato; e novos eleitores que não tinham ido votar no 1º turno mas compareceram no 2º. O balanço fecha exatamente: o total de votos que entraram é igual ao total que Lula e Flávio ganharam.

Comparando os números do 1º turno com os do 2º turno, município a município, conseguimos ver quanto cada candidato cresceu e de onde esses votos podem ter vindo. Transferência de votos (estimativa) ?Regressão ecológica é uma técnica estatística que estima, a partir dos totais de cada município, qual fração dos eleitores de cada candidato migrou para Lula ou Flávio. Não é 100% precisa, mas dá uma boa aproximação.

Para onde foram os votos dos candidatos eliminados no 1º turno? Usando regressão ecológica em 5.688 municípios, estimamos a fração que migrou para cada finalista.

Candidato Votos 1T → Lula → Bolsonaro IC 95% Distribuição

Metodologia: Regressão ecológica com restrições, usando dados de 5.688 municípios. R² = 0,997.

Ver mais sobre a metodologia

O problema: Não é possível saber diretamente para quem cada eleitor votou no 2º turno. O que temos são os totais por município em cada turno. A inferência ecológica estima os fluxos a partir desses agregados.

Modelo A2 — OLS com restrições e controles regionais: Para cada município, o crescimento de votos do Lula entre turnos é modelado como uma combinação linear dos votos de cada candidato eliminado no 1º turno, mais a variação de brancos, nulos e comparecimento. Os coeficientes (βᵢ) representam a fração estimada dos votos de cada candidato que migrou para o Lula. Todos os coeficientes são restritos ao intervalo [0, 1]. Para controlar o confounding geográfico (ex: um candidato forte no Nordeste poderia inflar artificialmente sua transferência para o Lula), o modelo inclui variáveis dummy regionais (Norte, Nordeste, Centro-Oeste e Sul, com Sudeste como base). Assim, a transferência é estimada dentro de cada região, eliminando o viés entre regiões. O modelo é resolvido via minimização de mínimos quadrados (scipy L-BFGS-B).

Modelo A3 — Bootstrap para intervalos de confiança: O modelo A2 (com controles regionais) é executado 200 vezes, cada vez com uma reamostragem aleatória de 80% dos municípios (com reposição). A variação dos coeficientes entre as reamostras produz uma distribuição que permite calcular intervalos de confiança de 95%.

Análise regional: Além do modelo nacional, o A2 é executado separadamente para cada região (Norte, Nordeste, Centro-Oeste, Sudeste, Sul). Ao passar o mouse sobre cada candidato, uma tabela mostra como o coeficiente varia por região. Quando há grande variação regional, é sinal de que a estimativa nacional pode ser influenciada pela distribuição geográfica do candidato.

Limitações:

  • Falácia ecológica: O modelo estima padrões agregados, não comportamento individual. A transferência real pode variar de município para município.
  • Candidatos pequenos: Candidatos com menos de 50 mil votos têm estimativas com alta incerteza (intervalos de confiança muito amplos).
  • Colinearidade: Candidatos de esquerda menores (UP, PSTU, PCB, PCO) tendem a ter distribuição geográfica semelhante, dificultando a separação individual.
  • Premissa de linearidade: O modelo assume que a fração de transferência é constante em todos os municípios. Na realidade, pode haver variação regional.

Qualidade do ajuste: R² = 0,9973 — o modelo explica 99,73% da variação observada no crescimento de votos do Lula entre turnos.

Abstenção entre turnos ?Abstenção é quando o eleitor podia votar mas não compareceu. No Brasil o voto é obrigatório, mas quem falta paga uma multa pequena (R$ 3,51). Normalmente a abstenção sobe no 2º turno, mas em 2026 aconteceu o contrário.

Brancos e nulos: quem protestou com o voto? ?Voto em branco é quando o eleitor aperta 'Branco' na urna, sem escolher candidato. Voto nulo é quando digita um número que não corresponde a nenhum candidato. Nenhum dos dois conta para decidir o vencedor.

Votar em branco ou anular o voto são formas de protesto ou indecisão. Este gráfico mostra quantos eleitores fizeram isso em cada turno. No 2º turno, com apenas dois candidatos, esses números costumam cair.

Onde cada partido é forte, quem ganhou para presidente? ?Esta tabela mostra coincidências geográficas, não comportamento individual. Um eleitor pode votar no PL para deputado e em Lula para presidente. Os dados mostram que, nas regiões onde certo partido é forte, um candidato presidencial tende a ir melhor — mas isso não prova que os mesmos eleitores votaram nos dois.

Dados processados diretamente dos Boletins de Urna (BUs) do TSE.
