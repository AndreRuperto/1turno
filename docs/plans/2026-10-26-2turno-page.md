# 2turno.html Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Create a standalone `2turno.html` page covering the Oct 25, 2026 presidential runoff and 6 gubernatorial runoffs, with full journalistic narrative, maps, tables, and charts.

**Architecture:** Single static HTML file mirroring `index.html` structure (same CSS tokens, fonts, SVG cartograma, dark/light mode). Shares the `1turno/` asset folder for favicon/logo. Links back to `index.html` and vice-versa.

**Tech Stack:** Vanilla HTML/CSS/JS, inline SVG, Google Fonts (Source Serif 4 + IBM Plex Sans), no build step.
